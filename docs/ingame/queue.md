# File des vérifications en jeu

Le cycle et les rôles : [README.md](README.md). L'agent du PC ajoute les demandes ; l'agent du Mac les fait faire en
jeu et consigne le résultat. La plus utile d'abord.

**Depuis le 2026-11-03, la vérification du jeu répond d'un coup à la part « ce nom existe-t-il ? » des demandes** :
l'addon contrôle seul, une fois par build du client, les fonctions, cadres, événements, modèles de cadre, atlas et
textures qu'il appelle (`core/check.lua`, `/fs check`) et range le résultat dans `ForeverSpeechDB.check`. L'agent du
Mac le lit dans les sauvegardes avant de demander un relevé `/run`.
